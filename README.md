# R3SPOND: Readiness, Response and Recovery – Security Procedure Organization and Navigation Device

R3SPOND is a framework for structuring the technical and organizational measures required during major cyber security incidents.
It builds on the NIST incident response lifecycle, but extends it into a more operational model by stretching out the original four phases and enriching them with practical steps that can be used checklist like.

> Since every security incident is unique, a project-specific implementation of the phases and their steps will still be required.

To allow responders, crisis managers and decision-makers to understand phases, objectives, responsibilities and measures without forcing them into a rigid linear process the framework is presented in a matrix-inspired structure to provide a high-level map of the incident response process.

## Installation und Build

Install mkdocs with all required plugins and theme:

        pip3 install mkdocs mkdocs-material mkdocs-macros-plugin mkdocs-glightbox mkdocs-static-i18n markdown-include pymdown-extensions

Build:

        mkdocs build
